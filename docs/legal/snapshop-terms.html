2. Permitted Use

You may use the App to:

  • Run real-time on-device object detection through YOLO26 NCNN.
  • Submit a compressed thumbnail of a detected object to a cloud multimodal AI service (Google Gemini via OpenRouter) for brand and model identification.
  • Browse third-party shopping platforms (Amazon, eBay, AliExpress) through an in-app WebView.
  • Pay for products with USDC on the Solana blockchain via Mobile Wallet Adapter, including the Bitrefill gift-card flow.
  • Optionally record detection events on Solana as Memo Program transactions.
